# Entrena en casa · 20 minutos

Plan de entrenamiento de 3 días por semana con peso corporal y bandas elásticas (10, 20 y 30 kg).

- Demostración animada de cada ejercicio, con pasos y errores a evitar.
- Nivel **Inicio** (versiones suaves para empezar) y nivel **Normal**.
- Modo **Entrenar**: temporizador guiado con calentamiento, circuito y estiramientos.
