# Entrena en casa

Plan de fuerza de 3 días con el kit de gomas PORTENTUM de 136 kg (8 gomas con asas), organizado en superseries, y un programa diario de cuello y trapecios.

- Animaciones de cada ejercicio hechas con Remotion (`anim/`), con los músculos que trabajan resaltados.
- Modo **Entrenar**: temporizador guiado con calentamiento, superseries y estiramientos, o la rutina de cuello.
- Vídeo de cómo anclar la banda a la puerta (`video/`).
